## 2. 基础要求

### T1 起摆成功率 ✅

- **测法**：F10 复位 → 等 1 s → 按 D11，重复 N 次；判"成功"为捕获后站住 ≥ 2 s
- **判据**：成功率 ≥ 90%
- **数据**：`docs/data/v30_S2.csv`（1.1 定版，200 s）、`docs/data/swing10.csv`（1.0，198 s）
- **实测（1.1，2026-11-03）**：

| 指标 | 数值 |
|---|---|
| 起摆尝试 | **11** 轮（第 11 轮起点过晚、数据不足，剔除） |
| 可判轮数 | 10 |
| **捕获后站住 ≥2 s** | **10 / 10 = 100%** |
| 捕获时间 | 中位 **1.14 s**，范围 1.11 ~ 1.16 s |

- **1.0 历史**：18 次尝试、17 次捕获（94%）、15 次站住（83%）；3 次失败均伴随 SA100 坏点。
- **图**：[fig4_capture_time.png](figures/fig4_capture_time.png)（1.0 数据）

### T2 起摆时间分解 ✅

- **判据**：起摆全过程 ≤ 3 s
- **实测**（读 state 机时间戳）：

| 阶段 | 耗时 |
|---|---|
| kick（state 1） | ≈ 250 ms |
| 反踢（state 2） | ≈ 250 ms |
| 泵能（state 3） | ≈ 550 ms |
| **kick → 捕获（state 5）** | **1.14 s（中位）** |

- **1.1 单次全过程**（`docs/data/v30_S1.csv`）：0 s 静止 → **6.76 s** 起 kick → 7.01 / 7.26 s 过 state 2/3
  → **7.91 s 进 state 5** → 此后连续平衡 22.1 s（到 30 s 抓包结束）。
- **结论**：远优于 3 s 判据；10 次成功样本全部落在 1.11~1.16 s，重复性很好。
- **图**：[fig1_swingup.png](figures/fig1_swingup.png)（1.0 数据）

### T3 平衡保持时长 ✅

- **测法**：起摆入稳后不接触，连续抓包 660 s，统计 `state=5` 的最长连续段
- **判据**：≥ 10 分钟（600 s）
- **数据**：`docs/data/v30_S4.csv`（660.07 s，66007 帧，20:38:54~20:49:54）
- **实测**：

| 指标 | 数值 |
|---|---|
| 最长连续平衡段 | **66007 帧 = 660.1 s**（11 分 00 秒） |
| 闭环段数 | 1 段（全程 state=5，无掉摆、无重摆） |
| 口径说明 | 抓包起点已在平衡态，故结论写作"**连续平衡 ≥ 660 s**"，不是"从起摆算起 660 s" |
| 1.0 历史 | 514.8 s（抓包比起摆早开约 85 s，故未满 600 s） |

### T4 平衡稳态精度 ✅

- **测法**：取 T3 最长闭环段全程统计（1.1 段首已在平衡态，无捕获瞬态需剔除）
- **判据**：\|θ\| p95 ≤ 3°；横臂漂移 ≤ ±15°
- **实测**（66007 帧）：

| 指标 | 1.1（660.1 s） | 1.0（514.8 s，历史） |
|---|---|---|
| \|θ\| p50 | **0.70°** | 1.70° |
| \|θ\| p95 | **1.60°** | 3.50° |
| \|θ\| rms | 0.86° | 2.03° |
| \|θ\| max | **2.40°**（范围 −1.80° ~ +2.40°） | 4.90°（含瞬态 13.0°） |
| duty mean\|.\| | 421（满量程 2500 的 17%） | 508 |
| duty 峰值 | **1161**（限幅 2000） | 1850 |
| **duty 饱和帧数** | **0** | 0 |
| 横臂净漂 | **−21 counts / −9.2°** | 77 counts / 33.6° |
| 横臂峰峰 | 33 counts | 127 counts |
| 横臂漂移速率 | **0.83 °/min** | 3.92 °/min |
| 抖动主频 | 8.03 Hz | 5.1 Hz |

- **结论**：θ 指标满足判据；横臂漂移由 3.9 °/min 降到 **0.83 °/min**（外环积分起效），11 分钟漂 9.2°，
  仍在"±15°"口径内。属外环无位置反馈的固有慢漂。
- **图**：[fig2_balance.png](figures/fig2_balance.png)（1.0 数据）

### T5 抗瞬时推扰 ✅

- **测法**：平衡中手工瞬时推扰，抓包 60 s
- **数据**：`docs/data/v30_S6.csv`（1.1 定版，60 s）、`docs/data/disturb3.csv`（1.0，120 s）
- **判据**：轻微/中等推扰能恢复且不倒
- **实测（1.1，复算口径：state5 内 \|θ\|≥4.5° 起判，2 s 内合并为一次推扰）**：

| 指标 | 数值 |
|---|---|
| 检出推扰 | **8** 次 |
| 未掉摆（恢复） | **8 次（100%）** |
| 各次峰值角 | 5.1° / 5.8° / 7.1° / 7.5° / **14.1°** / 7.1° / 7.1° / 5.0° |
| 恢复时间 | 0.19 ~ 1.33 s（回到 ±5° 内） |
| 单次推扰 duty 峰值 | 1974（99% 限幅），全程饱和 0 帧 |
| 横臂位移 | 净 −10 counts，峰峰 218 counts（≈95°，无位置环不自回） |

- **1.0 历史**：120 s 内 35 次推扰、33 次恢复（94%），可恢复峰值 26.7°。
- **说明（报告必须保留）**：推扰由人手施加，**力度不可标定**，因此以"实测摆杆峰值角"作为强度度量，
  而不是标称力/角度。
- **图**：[fig3_disturb.png](figures/fig3_disturb.png)（1.0 数据）

## 3. 拓展要求（当前空白）

> 这三项是赛题拓展分，**固件已经能跑，缺的只是抓包**。每项约 20~30 分钟。

### T6 跟随定位精度 ✅（单格已实测）

- **测法**：平衡后进轨迹页选"跟随"，旋钮转过一格（每格 18°），记录实际位移与收敛过程
- **判据**：单格位移误差 ≤ 3°；无明显持续振荡
- **数据**：`docs/data/v30_S7b.csv`（30.06 s，全程 state=5）
- **实测（FAST 档，目标 +18°）**：

| 指标 | 数值 |
|---|---|
| 目标角 | +18° |
| 稳态实测 | **+14.4°**（+33 counts） |
| 稳态误差 | **−3.6°** |
| 过程过冲 | 26°（59 counts），随后回落 |
| 收敛 | 约 1 s 内稳住 |
| 摆杆 \|θ\| p50 / p95 | 0.70° / **1.60°**（与纯平衡同，跟随未牺牲姿态） |
| duty 饱和 | 0 帧 |

- **结论**：单格阶跃能站住，但**静差 3.6° 超出 3° 判据**——外环无积分作用于 φ 目标（积分作用在绝对 θ），
  属结构性问题，见 [04_已知问题.md](04_已知问题.md) B-2。
- **未测**：其余三档速度、连续多格（3 格 = 54°）—— 大目标阶跃会掉摆，先不写进结论。

### T7 正弦轨迹 ✅（两档已实测）

- **测法**：轨迹页选正弦档，速度档选 NORMAL / FAST，各跑 30 s
- **判据**：摆杆 \|θ\| p95 ≤ 8°、不倒下
- **数据**：`docs/data/v30_S9.csv`（NORMAL）、`docs/data/v30_S10.csv`（FAST）
- **实测**：

| 速度档 | 频率（实测） | 幅度设定 | 实测幅度 | 跟踪率 | 摆杆 p95 | 是否倒 |
|---|---|---|---|---|---|---|
| NORMAL（屏显 60 °/s） | **0.245 Hz**（周期 4.084 s） | 35° | **±26.6°** | **76%** | 1.90° | 否 |
| FAST（屏显 90 °/s） | **0.351 Hz**（周期 2.848 s） | 50° | **±33.8°** | **68%** | 3.10° | 否 |

- **结论**：频率升高、跟踪率下降（76% → 68%），是位置环带宽不足的**干净低通特性**；
  两档全程 state=5、duty 无饱和。摆杆 p95 3.10° 说明 FAST 档姿态代价可用。
- **档位映射（重要）**：`bal_top.v:879-884` 的 `sin_step` = 10/16/23/33 → 0.15/0.25/0.35/0.50 Hz（4 档），
  实测频率与 `sin_step` 逐位吻合；OLED SPEED 页显示的是 **30/60/90/120 °/s**，与 `follow_slew` 注释里的
  10/20/50/100 不一致，见 [04_已知问题.md](04_已知问题.md) C-1。

### T8 速度档位实测 ⬜

- **测法**：同 T6，用横臂运动段的速度中位数衡量
- **屏显标称**：SLOW 30 / NORMAL 60 / FAST 90 / TURBO 120 °/s（`follow_slew` 注释写的是 10/20/50/100，不一致）

## 6. 已知限制（写报告的"限制说明"章节）

1. **跟随单格有 3.6° 静差**（目标 18° 得 14.4°），大目标阶跃仍会掉摆（拓展③只做了一半）
2. **横臂 0.83°/min 慢漂**（11 min 漂 9.2°），外环无位置反馈，属固有特性
3. **稳态 duty 8.0 Hz 抖振**（峰峰约 2300 counts），电机持续换向（1.1 相比 1.0 幅值腰斩、频率抬高）
4. **SA100 有随机坏点**，靠 3 点中值 + 4°/帧 门限 + 4 帧强制重同步兜住
5. **上电后需转动横臂唤醒**：SA100 在滑环死点无输出
6. **时序余量 9 ps**，没有改版空间
7. **速度档三处不一致**：OLED 屏显 30/60/90/120、`follow_slew` 注释 10/20/50/100、`sin_step` 4 档频率

详见 [04_已知问题.md](04_已知问题.md)。
