## 2. 基础要求

### T1 起摆成功率 ✅

- **测法**：F10 复位 → 等 1 s → 按 D11，重复 18 次；判"成功"为捕获后站住 ≥ 2 s
- **判据**：成功率 ≥ 90%
- **数据**：`docs/data/swing10.csv`（198 s，19817 帧）
- **实测**：

| 指标 | 数值 |
|---|---|
| 起摆尝试 | **18** 次 |
| 完成捕获（进 state 5） | 17 次（94%） |
| **捕获后站住 ≥2 s** | **15 / 18 = 83%** |
| 捕获时间（成功样本） | 中位 **1.14 s**，范围 1.10 ~ 1.77 s |

- **分析**：3 次失败中，1 次为上电首次（捕获耗时 8.58 s，站 0.4 s），2 次为捕获后瞬时失稳（站 0.3 s、0.9 s）。
  失败呈**间歇性**，与 SA100 坏点相关，不是代码退化。
- **图**：[fig4_capture_time.png](figures/fig4_capture_time.png)

### T2 起摆时间分解 ✅

- **判据**：起摆全过程 ≤ 3 s
- **实测**（读 state 机时间戳）：

| 阶段 | 耗时 |
|---|---|
| kick（state 1） | ≈ 250 ms |
| 反踢（state 2） | ≈ 250 ms |
| 泵能（state 3） | ≈ 550 ms |
| **kick → 捕获（state 5）** | **1.14 s（中位）** |

- **结论**：远优于 3 s 判据；15 次成功样本中 14 次落在 1.10~1.17 s，重复性很好。
- **图**：[fig1_swingup.png](figures/fig1_swingup.png)

### T3 平衡保持时长 ✅

- **测法**：起摆入稳后不接触，连续抓包 600 s，统计 `state=5` 的最长连续段
- **判据**：≥ 10 分钟
- **数据**：`docs/data/hold10min.csv`（600 s，60002 帧）
- **实测**：

| 指标 | 数值 |
|---|---|
| 最长连续平衡段 | **51478 帧 = 514.8 s**（8 分 35 秒） |
| 闭环段数 | 1 段（中途无掉摆、无重摆） |
| 差异说明 | 抓包比起摆早开了约 85 s，故未满 600 s |

### T4 平衡稳态精度 ✅

- **测法**：取 T3 最长闭环段，去掉段首 5 s 捕获瞬态
- **判据**：\|θ\| p95 ≤ 3°；横臂漂移 ≤ ±15°
- **实测**（51478 帧，稳态 50978 帧）：

| 指标 | 数值 |
|---|---|
| \|θ\| p50 | **1.70°** |
| \|θ\| p95 | **3.50°** |
| \|θ\| rms | 2.03° |
| \|θ\| max（稳态段） | **4.90°** |
| \|θ\| max（含捕获瞬态） | 13.00° |
| θ 范围（稳态） | −4.9° ~ +4.5° |
| duty mean\|.\| | 508（满量程 2500 的 20%） |
| duty 峰值 | 1850（限幅 2000） |
| **duty 饱和帧数** | **0** |
| 横臂净漂 | 77 counts / **33.6°** |
| 横臂峰峰 | 127 counts / 55.5° |
| 横臂漂移速率 | **3.92 °/min** |

- **结论**：θ 指标满足判据；横臂慢漂 3.9°/min 超出"≤±15°"的口径（8.6 min 漂了 33.6°），列为已知特性。
- **图**：[fig2_balance.png](figures/fig2_balance.png)

### T5 抗瞬时推扰 ✅

- **测法**：平衡中手工瞬时推扰，抓包 120 s
- **数据**：`docs/data/disturb3.csv`（120 s，12004 帧）
- **判据**：轻微/中等推扰能恢复且不倒
- **实测**（复算：state5 内 |θ|≥8° 的超阈事件，按 0.3 s 间隔合并为一次推扰）：

| 指标 | 数值 |
|---|---|
| 检出推扰 | 35 次 |
| 未掉摆（恢复） | **33 次（94%）** |
| 可恢复的最大峰值角 | **26.7°** |
| 掉摆 | 2 次（峰值角已在跌落轨迹上，无法单独分离） |

- **说明（报告必须保留）**：推扰由人手施加，**力度不可标定**，因此以"实测摆杆峰值角"作为强度度量，
  而不是标称力/角度。中位峰值 13.4°。
- **与旧记录的关系**：2026-11-03 的旧清单用的是另一种合并窗口，记为"33 次 / 31 恢复"；
  两种口径的结论一致（掉摆 2 次、可恢复峰值 ~27°）。
- **图**：[fig3_disturb.png](figures/fig3_disturb.png)

## 6. 已知限制（写报告的"限制说明"章节）

1. **跟随阶跃存在过冲**，且大幅跟随时会掉摆（拓展③未达成）
2. **横臂 3.9°/min 慢漂**，位置环阻尼不足
3. **稳态 duty 5.1 Hz 抖振**（峰峰 3620 counts），电机持续换向
4. **SA100 有随机坏点**，靠 3 点中值 + 40 counts 门限 + 50 ms 丢帧容忍兜住
5. **上电后需转动横臂唤醒**：SA100 在滑动环死点无输出
6. **时序余量 3 ps**，没有改版空间

详见 [04_已知问题.md](04_已知问题.md)。
