# 03 · 数据文件与复算方法

> 本文定义每个 CSV 的字段、每个判据的口径、以及怎么一条命令把报告里的数字重算一遍。
> **报告里出现的任何实测数字，都应该能在这里找到出处。**

---

## 1. 数据来源与链路

```text
FPGA 100 Hz 遥测（VOFA JustFloat，6 通道，115200）
   → tools/capture_raw.ps1（PowerShell 串口抓包，逐帧落盘）
   → docs/data/*.csv
   → tools/recompute_all.py（复算）/ tools/plot_measured.py（出图）
```

抓包脚本按 JustFloat 帧尾 `00 00 80 7F` 分帧，每帧 28 字节取 6 个 float32。

## 3. 字段定义

| 列 | 含义 | 单位 | 换算 |
|---|---|---|---|
| `t` | **帧序号**（不是毫秒） | 帧 | 秒 = `t / 100` |
| `theta` | 摆杆倾角 θ | 0.1° | ° = `theta / 10` |
| `duty` | 电机占空比 | counts | 2500 = 100%；限幅 ±2000 |
| `state` | 起摆状态机 `sw_state` | — | 0 停 / 1 kick / 2 反踢 / 3 泵能 / 4 滑行 / 5 平衡 / 6 掉摆 |
| `pos` | 横臂编码器相对计数 | counts | 824.5 counts/圈 → ° = `pos × 0.4366` |
| `ch0` | 原始 ch0 打包值 | — | `state = (ch0>>4)&7`，`sensor_lost = (ch0>>7)&1` |
| `ch5` | 原始 ch5 打包值 | — | `{sw_inv_r, e_dbg[14:0]}`，起摆能量诊断 |

> ⚠ `t` 是**帧序号**不是毫秒。`capture_raw.ps1` 里 `$n` 自增后直接写进第一列，
> 按 100 Hz 换算成秒要 `÷100`。别直接当 ms 用（会差 10 倍）。

---

## 4. 判据口径（统一）

| 量 | 定义 |
|---|---|
| **起摆成功** | 进入 `state=5` 后连续保持 ≥ **2 s**（不是"碰到 state5 就算"） |
| **捕获时间** | `state` 由 1 变为 5 的时间差 |
| **连续平衡段** | `state=5` 的最长连续帧数 ÷ 100 |
| **稳态段** | 最长平衡段**去掉前 5 s**（捕获瞬态） |
| **θ 统计** | 在稳态段上算 p50 / p95 / rms / max，取绝对值 |
| **duty 饱和** | `\|duty\| >= 2000` 的帧 |
| **横臂漂移** | 段内 `pos` 末值 − 首值（净漂）与 `max − min`（峰峰） |
| **一次推扰** | `state=5` 内 `\|θ\| >= 8°` 的超阈事件，间隔 < 0.3 s 的合并为一次 |
| **回正时间** | 峰值那一帧起，到 `\|θ\|` 连续 0.5 s 都在 2.5° 以内为止 |

## 7. 抓包（补测 T6/T7/T8 时用）

```powershell
cd <仓库根目录>\tools
.\capture_raw.ps1 -Port COM6 -Seconds 60 -Out "..\docs\data\follow_g0.csv"
```

> `capture_raw.ps1` 默认只写 4 列（t/theta/duty/state）。
> `docs/data/` 里的 4 个文件是 7 列版本（含 pos / ch0 / ch5）抓的，
> 补测时若要用横臂位移（T6/T8 必须），需要把 `pos` 和 `ch0` 两列补进脚本 —— 见脚本内解析偏移。
