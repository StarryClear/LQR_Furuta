## 一、测量方法（可复算）

- COM6、100 Hz JustFloat，原始逐帧落盘（`tools/dist_logs/rawXX.csv`，字段 `序号,θ(0.1°),duty,state`）。
- 只在 `state=5` 的帧上统计。
- "回正时间"定义：从峰值那一帧起，到 |θ| 回到 **2.5°** 以内并**保持 0.5 s** 为止。
  （本体稳态就在 ±2° 里持续晃，所以不能定 0.5° 那种"绝对静止"判据，否则永远等不到。）
- 频谱：1000 点 Hanning 窗 FFT。

3.6 的 duty 频谱把问题定死了：

```text
duty  主频 11.4 Hz（相对幅值 1.00）、11.5 Hz（0.92）
theta 主频 0.6 Hz（摆动本体），11.4 Hz 只占 0.2
```

## 四、两个根因

1. **5.6° 饱和**：`KTH=4600` 让 duty 在 |θ|≈5.6° 就打满 ±2000。超过这个角度控制器只剩 bang-bang，
   而饱和时 D 项（KDT=60，500°/s 时才 117）在 2000 面前等于零 —— 所以任何把摆推过 5.6° 的干扰
   都会进入**无阻尼乒乓振荡**（±10°、持续 5~10 s）。这就是"回正慢"的真正原因。
2. **11.4 Hz 机械结构共振**：duty 里它是绝对主峰，θ 里只有 0.2。D 项等于在这个频点上做正反馈，
   所以 **KDT 一提高就自激**（3.1/3.6 的现象）。这也解释了为什么"加阻尼"和"消抖"在这台机器上互相打架。

## 五、下一步（按性价比排序）

1. **11.4 Hz 陷波器**（二阶，深度 10~15 dB，Q≈3）放在 D 项前。
   和 5 Hz 低通的区别：陷波只削 11.4 Hz 附近，不会给 1.5 Hz 的摆动加 64 ms 滞后 —— 3.7 就是死在滞后上。
   实现：`y[n] = b0·x[n] + b1·x[n-1] + b2·x[n-2] − a1·y[n-1] − a2·y[n-2]`，用 Q15 定点，1 kHz 更新。
2. 陷波做完再重试 **KTH 3600 + KDT 120**（饱和点 7.2°，ζ≈0.45），这是"刚度/阻尼"的折中点。
3. 机械：把摆杆与法兰的夹紧再紧一档、横臂加一条加强筋；共振频率若能抬到 25 Hz 以上，
   D 项就可以直接用，不需要陷波。
4. 更彻底：用状态观测器（或对 θ 做双线性滤波）替代 4 ms 差分的 θ̇，从源头把噪声压下去。

## 七、11.4 Hz 陷波器设计（下次直接实现）

设计参数：f0=11.4 Hz、fs=1 kHz、Q=3（−3 dB 带宽 ≈3.8 Hz）。

```text
alpha = sin(w0)/(2Q) = 0.011928
b0 = 1/(1+alpha)      =  0.988212   -> Q15  32382
b1 = -2cos(w0)/(1+a)  = -1.971368   -> Q15 -64597
b2 = b0               =  0.988212   -> Q15  32382
a1 = b1               = -1.971368   -> Q15 -64597  （差分方程里取 -a1 = +64597）
a2 = (1-a)/(1+a)      =  0.976427   -> Q15 -31996  （差分方程里取 -a2 = -31996）
```

差分方程（输入 x = θ̇，先右移 3 位防止 32 位溢出）：

```verilog
y[n] = ( 32382*x[n] - 64597*x[n-1] + 32382*x[n-2]
        + 64597*y[n-1] - 31996*y[n-2] ) >>> 15;
```

实现注意：

1. x 先 >>> 3（θ̇ 0.1°/s 量级 ±20000 → ±2500），输出再 <<< 3 还原；
   否则 2500×64600≈1.6e8 的乘积在 5 项相加时会溢出 int32。
2. 5 个乘法 + 加法树不能在 1 拍里做完（会掉 Fmax）。分两拍：
   第 1 拍把 5 个乘积存寄存器，第 2 拍求和并更新 y1/y2（用 tick1k 与其延时打拍）。
3. 陷波器只放在 **D 项**前面，P/KI/KDP 不动。
4. 上板后先用 FFT 验证：8~15 Hz duty 能量占比应从 3.0 的 4% 不变（陷波只作用在 D 上，
   且 D 只有 KDT·y，y 在 11.4 Hz 被压 ~20 dB），同时 KDT 提到 100~140 时不再出现 30% 那种爆表。

验证判据（和 3.8 对比）：KDT=100 + 陷波，8~15 Hz 能量占比应 ≤ 6%，且 13° 干扰回正 ≤ 3 s。
